### 一、我完成的具体工作

1. **账单列表与交互**
   - 实现数据按日期倒序渲染、单条记录删除功能
   - 支持按起止日期、收支类型、类别、最低/最高金额六维筛选
   - 支持"查看全部记录 / 只看最近10条"列表条数切换

2. **统计看板与图表**
   - 开发总收入 / 总支出 / 结余三个 KPI 卡片
   - 基于 Chart.js 绘制分类支出饼图（doughnut）、月度收支柱状图（bar）
   - 统计结果始终跟随筛选条件实时联动刷新

3. **技术细节处理**
   - 前端金额"分转元"格式化（后端返回整数分）
   - 使用请求序号（`reqId`）防止快速筛选时的旧数据覆盖新结果
   - 使用 `textContent` 替代 `innerHTML` 防止 XSS
   - 图表刷新前 `destroy` 旧实例，防止内存泄漏和叠加渲染

4. **接口协作**
   - 与录入模块队友通过 Flask API（`/api/records`、`/api/stats`）解耦协作
   - 本地基于 Flask (Werkzeug) 开发服务器运行，数据持久化至 SQLite

---

### 二、遇到的问题与解决方法

| 问题 | 解决方法 |
|------|---------|
| 快速切换筛选时旧请求后返回，覆盖新结果 | 引入 `reqId` 请求序号机制，回调时校验，丢弃过期响应 |
| Chart.js 多次刷新导致画布叠加、tooltip 异常 | 每次重建图表前调用 `destroy()` 销毁旧实例 |
| 用户输入（备注/类别）直接渲染存在 XSS 风险 | 统一使用 `textContent` 插入 DOM 节点 |
| 列表 limit 切换时统计数字跟着变，失去全局意义 | 统计接口独立调用，不传 `limit` 参数，保证汇总始终基于全量数据 |
